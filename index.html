Background

Sales first, tech always.

I studied Computer Science, ended up in sales, and never stopped building things. Alongside the selling, I made the tools I use every day for quoting, following up leads, running campaigns and reporting. I made them because I could. Each one fixed something in my own work, and most would be just as useful somewhere else.

Start with my own day

I only build something when a problem is already costing me time, money or sales. I'm not hunting for places to use a technology.

Cut the manual work

If a job is repetitive and follows rules, a computer should do it. That leaves me time for the parts that need a person.

Make it better for the customer

Quicker and more consistent for them, as well as cheaper for us. Usually that turns out to be the same fix.

Check it worked

If I can't point to something that changed, the job isn't finished.

Tools I've built

Five tools I built to fix problems in my own work.

I built these for a removals company, but the problems aren't specific to removals. Slow quotes, leads going cold and follow-ups slipping through the cracks happen in most businesses that sell.

I know software already exists that does all of this. The difference is that I tailored each of these tools to what I actually need, and the software itself cost nothing to build. Any running costs, like Twilio for texts, are paid for by the business.
